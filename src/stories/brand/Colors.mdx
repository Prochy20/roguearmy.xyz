# Colors

The RGA palette is a **two-layer system** built for dark cyberpunk interfaces.

- **Layer 1 — raw palette.** Seven brand-saturated hex values. Use directly via `text-rga-*` only when no semantic name applies (rare).
- **Layer 2 — semantic aliases.** Names that describe what the color *does* in context (`status-warn`, `game-d2`, `role-mod`). Components reference these. Same hex may back multiple aliases when surfaces don't coexist on one screen.

The single biggest rule that keeps this system coherent: **chrome stays RGA-neutral; body wears game color**. The persistent top ribbon and nav are always green/muted/white regardless of section. The page body under `/division-2/*` wears `game-d2` (orange). Future game sections each get their own brand color, but the chrome frame never changes.

Values below come from `src/lib/design-tokens.ts`. Both this page and the `/brand` route on the live site read from the same source.

## Layer 1 — raw palette

These are the seven hex values the system is built on. Prefer Layer 2 aliases in components; reach for these only when no semantic fits.

- **Green** `#00FF41` — RGA brand identity. Logo, primary CTAs, selection, scrollbar.
- **Cyan** `#00FFFF` — alternative voice. No fixed semantic — use when green would be wrong or you need a second neon flavor.
- **Magenta** `#FF00FF` — decorative only. Powers `text-chromatic`, RGB-shift glitch effects, gradient ends. **Not** used for status anymore.
- **Orange** `#FF8000` — Division 2 game brand (`game-d2`) and Moderator staff role (`role-mod`). Same hex, different surfaces.
- **Chartreuse** `#CCFF00` — exclusively for Developer staff role (`role-dev`). Don't repurpose.
- **Yellow** `#FFE100` — Hazard Yellow. Status warning (`status-warn`) — STALE, MEMBERS-ONLY gates, soft attention.
- **Rose** `#FF0066` — Status error (`status-error`) and Admin staff role (`role-admin`). Same hex, different surfaces.

## Background colors

Four levels of darkness create depth and hierarchy. Layer them from dark to light: **Void → Primary → Elevated → Surface**. Never skip levels.

  {BG_COLORS.map((c) => (
    <ColorItem key={c.hex} title={c.name} subtitle={c.tailwind} colors={{ [c.name]: c.hex }} />
  ))}
</ColorPalette>

## Text colors

Three text hierarchy levels:

- **Primary** (#FFFFFF) — headings and important content.
- **Secondary** (#888888) — body text and descriptions.
- **Muted** (#555555) — labels, timestamps, placeholders, disabled text.

<ColorPalette>
  {TEXT_COLORS.map((c) => (
    <ColorItem key={c.hex} title={c.name} subtitle={c.tailwind} colors={{ [c.name]: c.hex }} />
  ))}
</ColorPalette>

> Never use brand colors (green, cyan, magenta) for long-form body text — they are for short labels, links, and accents only.

## Glow colors

Semi-transparent versions of palette colors, used exclusively for `box-shadow` and `text-shadow` glow effects. These create the signature neon luminosity that defines the cyberpunk aesthetic.
