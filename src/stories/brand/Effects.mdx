# Effects & animations

These effects create our cyberpunk identity. Each one is purpose-built — use them intentionally. Overuse dilutes their impact.

**The general rule**: one major effect per viewport, subtle effects can stack.

For interactive playgrounds with full prop controls, see the individual component stories in `Components/Effects/*`.

## Text glow

Adds neon luminosity to text using layered `text-shadow`. Best on display-size headings or single keywords you want to emphasize. Avoid applying to body text or long strings — the blur makes them harder to read.

<div style={{ display: 'flex', gap: '2rem', flexWrap: 'wrap', justifyContent: 'center', padding: '2rem', border: '1px solid rgba(0,255,65,0.3)', background: '#0A0A0A' }}>
  <p style={{ fontFamily: '"Hanson Bold", sans-serif', fontSize: '1.5rem', textTransform: 'uppercase', color: '#00FF41', textShadow: '0 0 10px rgba(0,255,65,0.8), 0 0 20px rgba(0,255,65,0.5), 0 0 30px rgba(0,255,65,0.3)', margin: 0 }}>Green Glow</p>
  <p style={{ fontFamily: '"Hanson Bold", sans-serif', fontSize: '1.5rem', textTransform: 'uppercase', color: '#00FFFF', textShadow: '0 0 10px rgba(0,255,255,0.8), 0 0 20px rgba(0,255,255,0.5), 0 0 30px rgba(0,255,255,0.3)', margin: 0 }}>Cyan Glow</p>
  <p style={{ fontFamily: '"Hanson Bold", sans-serif', fontSize: '1.5rem', textTransform: 'uppercase', color: '#FF00FF', textShadow: '0 0 10px rgba(255,0,255,0.8), 0 0 20px rgba(255,0,255,0.5), 0 0 30px rgba(255,0,255,0.3)', margin: 0 }}>Magenta Glow</p>
</div>

```html
<span className="text-rga-green text-glow-green">…</span>
<span className="text-rga-cyan text-glow-cyan">…</span>
<span className="text-rga-magenta text-glow-magenta">…</span>
```

## Box glow

Box-shadow glow applied to containers and cards. Use with a matching border color at reduced opacity. Ideal for featured cards, active states, and focused elements.

<div style={{ display: 'flex', gap: '1.5rem', justifyContent: 'center', padding: '2rem', border: '1px solid rgba(0,255,255,0.3)', background: '#0A0A0A' }}>
  <div style={{ width: '5rem', height: '5rem', border: '1px solid rgba(0,255,65,0.6)', boxShadow: '0 0 20px rgba(0,255,65,0.5), 0 0 40px rgba(0,255,65,0.3)' }} />
  <div style={{ width: '5rem', height: '5rem', border: '1px solid rgba(0,255,255,0.6)', boxShadow: '0 0 20px rgba(0,255,255,0.5), 0 0 40px rgba(0,255,255,0.3)' }} />
  <div style={{ width: '5rem', height: '5rem', border: '1px solid rgba(255,0,255,0.6)', boxShadow: '0 0 20px rgba(255,0,255,0.5), 0 0 40px rgba(255,0,255,0.3)' }} />
</div>

```html
<div className="border border-rga-green/60 glow-green" />
```

## Chromatic aberration

Simulates RGB channel misalignment from a broken CRT screen. The static version adds permanent cyan/magenta text-shadows; the animated version pulses the offset.

**Live playground**: see `Components/Effects/ChromaticText` for interactive controls.

```tsx
import { ChromaticText } from '@/components/effects/ChromaticText'

<ChromaticText as="h2">Section Title</ChromaticText>
<ChromaticText as="h1" animated>Hero Title</ChromaticText>
```

Use on section headings and brand moments. The `as` prop controls the HTML element (`h1`, `h2`, `h3`, `span`, `p`, `div`).

## Gradient text

Applies the full brand gradient (green → cyan → magenta) as a text fill. Use for feature titles, promotional headings, or anywhere you want the full spectrum on text. Always pair with Hanson Bold at display sizes for best effect.

```html
<p className="font-display text-5xl uppercase text-gradient-rga">ROGUE ARMY</p>
```

## Glitch text

A brief digital distortion burst with RGB chromatic split. **Live playground**: see `Components/Effects/GlitchText`.

Three trigger modes:

- `hover` — on mouse enter
- `scroll` — once on viewport entry
- `always` — continuous loop

```tsx
<GlitchText trigger="hover">Hover Me</GlitchText>
```

## Scanlines

CRT-style horizontal scanlines that sweep across content. **Live playground**: see `Components/Effects/ScanlineOverlay`.

Apply at the page/section root with low intensity (`intensity="low"`) as ambient atmosphere. Higher intensities (`medium`, `high`) work for specific scenes but become visually noisy if left on globally.

## Noise overlay

Subtle animated static/grain texture over an element. Apply to any container with `position: relative` and `overflow: hidden`. Keep it subtle — this is background texture, not a foreground effect.

```html
<div className="relative overflow-hidden noise-overlay">
  ...
</div>
```

---

> **Don't overdo it.** A page with every effect active simultaneously feels chaotic. Use HeroGlitch for one hero heading per page, ChromaticText for section headings, GlitchText for interactive moments, and `text-glow-*` for single keyword emphasis. The scanline overlay and noise texture are ambient — they can run page-wide at low intensity.
